# Subscription & Monthly Burn Tracker

Track your software subscriptions and see your monthly spending at a glance.

**Live demo:** https://subscription-tracker-r2u5.onrender.com/

## Features

- Sign up and log in (JWT authentication)
- Add, edit, cancel and delete subscriptions
- Monthly burn rate, yearly projection and spending by category
- Upcoming renewals in the next 30 days

## Tech Stack

React, TypeScript, Node.js, Express, PostgreSQL, JWT, Docker, GitHub Actions, Jest, Vitest
